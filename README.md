# big-research — 큰 자료조사 스킬 (v1.2)

Claude가 **수십~수백 건을 모아 사람이 고르게 하는 조사**(레퍼런스 보드·사례집·업체 목록·게시물 모음)나 **공개 데이터를 모아 대조·계산하는 조사**를 끝까지 진행할 때 따르는 절차와, 그 절차를 받치는 파이썬 코드입니다.

큰 조사는 «많이 찾는 것»보다 «찾은 것이 진짜인가 · 중복은 없나 · 사람이 빨리 고를 수 있나»에서 무너집니다. 실제 조사에서 있었던 실패 — 주소 문자열로 중복을 거르다 서로 다른 영상 34건 누락, «열어 봤다»던 링크 중 없는 페이지, 요약 숫자와 데이터 불일치, 저장 전 인코딩 오류로 결과 유실 — 를 막도록 만들었습니다.

## 무엇을 하나
- 비용 견적과 더 싼 방법 → 조사 한 장(목적·기준선·필드·상태값·근거 강도·완료 기준)
- 경로별 접근 표본시험 → 하위 조사 에이전트 + **독립 2차 조사**(다른 AI·동료)용 지시문
- `scripts/norm_id.py` — 유튜브·X·틱톡·인스타·스레드·일반 웹 **고유 ID 로 중복 거르기**(애매하면 합치지 않음)
- `scripts/link_check.py` — 링크 **실재 확인 + 근거 문장 원문 대조** + 충돌 목록(애매하면 «열림»으로 확정하지 않음)
- `scripts/rounds.py` — 호출 1회마다 회차 저장(덮어쓰기 0) · `scripts/ledger.py` — 유료 호출 비용 장부·상한
- `scripts/cards_html.py` — 카드형 **고르는 화면**(거르기 칩 · 좋음/안 듦 · 고른 번호 복사)
- 파이썬 3.8 이상 · 외부 패키지 0 · 시험 136건(`scripts/` 에서 `python -m pytest -q`)

## 쓰는 법
«고급 정육점 브랜드 레퍼런스 40개 모아서 고르게 해줘», «AI 영상 사례 50편 찾아서 기준집 만들어줘», «공개 낙찰가 데이터로 우리 매입가 비교해줘»처럼 요청합니다. 스킬이 비용 견적과 조사 한 장을 먼저 보여 주고, 확인 뒤 진행합니다.

## 외부로 보내거나 가져오는 것
- `scripts/link_check.py` 는 사용자가 준 항목의 **URL 에 HTTP 요청**을 보냅니다(robots.txt 확인 · 요청 간격 1초 · 재시도 1회). 유튜브 주소는 `youtube.com/oembed` 로 제목·채널만 조회합니다. 로그인이 필요한 사이트(인스타그램·페이스북·X·틱톡·스레드·네이버 등)는 **열지 않고** «미확인»으로 둡니다.
- 그 밖의 스크립트는 로컬 파일만 읽고 씁니다(회차 JSON · `seen_ids.txt` · 비용 장부 sqlite/JSONL · HTML).
- 2차 독립 조사·외부 검토 지시문은 **텍스트로만 만듭니다.** 다른 AI나 사람에게 보낼지는 사용자가 직접 정하고 직접 전달합니다.
- 개인정보를 수집하지 않으며, 스킬 작성자에게 데이터가 전송되거나 보관되지 않습니다. 유료 API 를 쓸 때는 사용자가 정한 상한 안에서만(`ledger.py`) 호출하도록 안내합니다.
